Create a mobile-first Progressive Web App called MORPHDRAWER.

MORPHDRAWER is an atmospheric sketchbook experience for beginner artists. It should feel like a living notebook filled with evolving creatures, haunted doodles, emotional relics, soft monsters, strange objects, and sketch companions.

The app should feel:

* hand-crafted
* tactile
* emotionally alive
* cozy
* weird
* imperfect
* playful
* atmospheric
* beginner-friendly

Avoid:

* corporate UI
* sterile minimalism
* startup aesthetics
* glassmorphism
* overly technical interfaces
* hyper-complex AI systems
* intimidating professional art tools

The emotional goal:
“A haunted little sketchbook that gently teaches beginners how to draw weird lovable things.”

⸻

CORE PURPOSE

Users generate simple drawable forms:

* creatures
* mascots
* haunted objects
* relics
* tiny gods
* soft monsters
* cursed plushies
* abstract companions
* emotional doodles

The app should help users:

1. generate a form
2. instantly understand how to draw it
3. evolve it into new versions
4. emotionally connect with the notebook

The experience should encourage:

* messy creativity
* experimentation
* imperfect sketching
* playful drawing
* emotional expression

⸻

OUTPUT FORMAT

Every generated form should contain:

1. What Is It?
    Short concept.
    Examples:

* sleepy mushroom creature
* nervous lamp ghost
* tiny moon robot
* lonely backpack spirit

⸻

2. Main Shape
    Simple shape language:

* round
* square
* chunky
* floppy
* triangle
* noodle-shaped
* spiky
* tall
* tiny

⸻

3. Face
    Simple facial concepts:

* button eyes
* sleepy dots
* stitched mouth
* tiny fang
* crooked smile
* star nose

⸻

4. Body Details
    Only 2–4 memorable features:

* floating hands
* oversized sleeves
* leaf tail
* dangling charms
* cracked shell
* tiny legs

⸻

5. Texture + Materials
    Easy visual surfaces:

* plush
* paper
* cracked paint
* graphite
* ceramic
* fuzzy
* jelly-like
* shiny plastic

⸻

6. Colors
    3–5 emotionally named colors:

* attic blue
* bruised lavender
* dusty mint
* candle yellow
* raincloud gray

⸻

7. Personality
    Short emotional presence:

* shy but curious
* sleepy guardian
* dramatic little menace
* lonely but friendly
* chaotic sweetheart

⸻

8. Evolution Idea
    Simple mutation:

* grows extra eyes
* sleeves become wings
* face cracks slightly
* symbols spread
* colors darken
* body stretches taller

⸻

9. Drawing Tip
    Beginner-friendly advice:

* start with circles
* exaggerate the eyes
* draw silhouette first
* keep limbs simple
* make one feature oversized

QUICK SKETCH MODE

The app should prioritize beginner confidence.

Default view should only show:

* What Is It
* Main Shape
* Face
* Drawing Tip

Everything else expands optionally.

“This is too complicated.”
